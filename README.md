# Simurail Shenanigans Modpack
I'll host the modpack's packwiz here because its a nice free way to host it and doubles as source control. This pack will manage configs for the server too, so players can run the pack in singleplayer and get the same experience as in the server, sans multiplayer and it being super duper cool and sick and shit and super cool so please join the server <3

The main branch will contain the latest version of the modpack while the dev branch will contain mods and configurations we are testing before pushing them to players, you can also use tag references to pin to a specific version of the modpack:

- DEV branch (Testing): `https://raw.githubusercontent.com/StellarSt0rm/packwiz/refs/heads/dev/pack.toml`
- MAIN branch (Current): `https://raw.githubusercontent.com/StellarSt0rm/packwiz/refs/heads/main/pack.toml`
- TAG reference (Pinned): `https://raw.githubusercontent.com/StellarSt0rm/packwiz/refs/tags/v?.?.?/pack.toml`
